## 1. 人群与随机化单位

- [x] **决定（Andy，2026-10-01）：实验人群 = P3 测试集全体，截止日 11-18 打分的 2,305,679 人，不只取高分段**。
  分数只读 MLflow `pte-purchase-propensity` 第 1 版（`scripts/score_users.py --cutoff 2019-11-18 --version 1`），
  十分位按 `assign_deciles`（第 1 档 = 分数最高的十分之一；并列分数同档，所以各档人数不完全相等）。
  - 理由：全体随机后，第 1 档那部分人本身就是一次完整的随机实验，人和分组都与「只在第 1 档做」完全相同，
    所以只做高分段能回答的问题，全体都能回答；反过来，只做高分段就没法逐档估效应，
    「发给最高分」对「发给最高增量」的策略对比也做不了。
  - 代价：真实业务里等于给低分段也发了券。生产上的对应做法是「主策略 + 小块随机探索流量」，
    探索切片常取 5–10% 来省券；本项目的券成本是模拟的，不真实发生，所以把探索开到全量来换精度。
- 随机化单位 = `user_id`；观察期 11/18–11/30（13 天，`incident_2019_11_15.md` 第 4.3 节）。

## 2. 分组

- [x] **决定（Andy，2026-10-01）：处理组 : 对照组 = 50 : 50；不分层，对 `user_id` 加盐哈希做简单随机**。
  - 总人数 N 固定时，两臂转化率之差的标准误
    `SE = sqrt( p(1-p) × ( 1/(f·N) + 1/((1-f)·N) ) ) = sqrt( p(1-p) / (f(1-f)·N) )`，
    在处理组占比 f = 0.5 时最小，f 与 1-f 对称。
    例：90/10 的方差是 50/50 的 (1/0.09) / (1/0.25) = 25/9 ≈ 2.78 倍，SE 是 5/3 ≈ 1.67 倍，
    即 MDE 放大 1.67 倍，或者总人数要多 2.78 倍才能追平。
  - 真实业务会怎么选：券成本落在处理组，常用 10/90（处理组小）省券；
    已经在发券、要证明增量时用 90/10（留 10% holdout 对照）。本项目券成本是模拟的，取精度最高的 50/50。
  - 不分层：每档约 23 万人，简单随机下两臂人数的偏差很小。SRM 检查以**全体**为准，逐档的检查只作诊断。
  - 盐和哈希函数写进代码和配置，固定后不再改（改了就等于重新分组）。
- [x] **决定（Andy，2026-10-04）：桶号 = int(sha256(f"{盐}:{user_id}"), 16) % 100，桶号 < 50 进处理组；正式的盐 = `"p4-coupon-2026-10"`，在计算它的分组之前写定**。
  - 每个人的分组只由自己的 `user_id` 和盐决定，与行的顺序、别的用户无关；同一个盐永远得到同样的分组，换盐就是一次独立的新分组
    （A/A 模拟换盐重分组靠的就是这一点）。

  | 0.05 | 1/20 | 约 2,100 人分错（占比偏 0.09pp） |

  - 检验：两比例差的双侧 z 检验，α = 0.05，SE 用合并的转化率（原假设下两臂只有一个共同的转化率）：
    ```
    diff = r_T − r_C，r_pool = (x_T + x_C) / (n_T + n_C)
    z = diff / sqrt( r_pool(1 − r_pool) × (1/n_T + 1/n_C) )，p = 2 × (1 − Φ(|z|))
    ```
    指标两个：① 全体转化率，② 第 1 档（主检验所在档）转化率。全体人均 GMV（Welch t）和逐档 10 个 + Holm 不纳入。
  - 通过标准，两个指标各自判定：
    ① 1000 次里 p < 0.05 的次数在 **37–64** 之间（Binomial(1000, 0.05) 的 2.5% / 97.5% 分位，`binom.ppf` 实测；
    检验正确时落在区间外的概率 = 4.19%）；
    ② 1000 个 p 值对 Uniform(0, 1) 做 KS 检验，p ≥ 0.05；20 箱直方图（每箱期望 50）只作展示。
    依据：原假设下 z ~ N(0, 1)，P(p ≤ a) = P(|z| ≥ z_{1−a/2}) = a 对任意 a 成立，即 p ~ Uniform(0, 1)；误报率 5% 是 a = 0.05 的特例。
  - 诊断，不作判据：1000 个 diff 的标准差应约等于公式的 SE（按 `y0` 实测：全体 0.027pp，第 1 档 0.155pp）。
  - 4 个判据（2 个指标 × 2 个标准）在检验正确时各有约 5% 的机会不通过，合起来最多约 20%（Bonferroni 上界；两个指标的 p 值相关，实际更低）。
    所以不通过时先查代码和公式，**不换盐、不换检验重跑到通过为止**，与 SRM 同一个纪律；结果无论通过与否都如实写进本节。

## 3. 主检验与逐档的探索性检验

- [x] **决定（Andy，2026-10-01）：预注册的唯一主检验 = 第 1 档（top 10%）内处理组与对照组的转化率差**。
  这是生产上会发券的那一段；其余 9 档的逐档效应、策略对比都标为**探索性**，
  主检验只有一个，多重比较不压主结论。
- [x] **决定（Andy，2026-10-01）：主检验的段锁定为 top 10%，不跟着工作点变**。
  `leakage.md` 3.4 节已定工作点在验证集的利润曲线上挑；挑出的 k 若不是 10%，作为策略结果另报，主检验不改。
  - 理由：10% 沿用 P3 报告的 lift@10%（「券发给第 1 档」），是看实验结果之前就定下的切点；
    若跟着挑出的 k 走，主检验的段就成了看数据挑的。

- [x] **决定（Andy，2026-10-03）：逐档的探索性分析分两层——估计和 CI 不校正；「哪几档显著」的结论用 Holm 校正**。
  - 10 档人群互不重叠、检验独立；若 10 档真实效应全为 0，至少一档误报的概率 = 1 − 0.95^10 = 40.1%。
  - 估计和 CI：每档报未校正的 95% CI，标为探索性。还原检验要看每档 CI 的覆盖率是否约 95%，
    用校正后更宽的 CI，覆盖率本来就会高于 95%，就检验不出 CI 是否名副其实。
  - 显著性结论：p 值同时报原始值和 Holm 校正值。Holm 控制 FWER ≤ 5%，功效至少和 Bonferroni 一样，所以不用 Bonferroni；
    不用 BH，因为只有 10 个检验，要的是「列出的每一条都可信」，不是「错的占比不高」。
  - 代价（按第 5 节的 τ，Bonferroni 作下界）：第 2 档功效 45% → 17%，第 10 档 63% → 31%，第 3–8 档几乎不变。
  - 主检验只有一个（第 1 档），不校正。
  - 留意赢家诅咒：策略对比挑「估计效应最大的档」时，挑中的估计值偏高（第 9 步处理）。

  - 数据：`features/test/outcomes` + 正式分组（盐 `"p4-coupon-2026-10"`，SRM p = 0.0175 不报警）。**处理组读 `y1`、`gmv1`，对照组读 `y0`、`gmv0`**，
    即实验实际看得到的那一列；全体 2,305,679 人，不丢任何人。只报原始估计，CUPED 在第 7 步。
  - **主检验**（第 1 档转化率差）：`z_test`，合并 SE，双侧 α = 0.05，不变。**显著与否只看 z 检验的 p**。
  - **转化率差的 95% CI 用不合并的 SE**（Wald）：
    ```
    SE_不合并 = sqrt( r_T(1 − r_T)/n_T + r_C(1 − r_C)/n_C )，CI = diff ± 1.96 × SE_不合并
    ```
    检验在原假设下算，两臂共用一个转化率，所以合并；CI 要覆盖任意的真实效应，不假设两臂相等，所以各用各的。
    两臂人数相等时两种方差之差 = (r_T − r_C)² / (2n)，diff 约 0.1pp 时相对差约百万分之一；但在边界上可能出现「p 略小于 0.05、CI 含 0」，
    此时以 p 为准，CI 照实报告。第 1 档每臂约 19,000 个买家，远超 Wald 区间对 n·p 的要求，不用 Wilson。
  - **次要指标**（不参与主结论）：
    ① 全体转化率差：方法同主检验。真值 0.330pp，SE 约 0.029pp（全体 MDE 0.080 / 2.80），约 11 个 SE，预期显著。
    ② 人均 GMV 差，第 1 档和全体：Welch t 检验，CI = diff ± 1.96 × sqrt(s_T²/n_T + s_C²/n_C)。处理组多了注入的买家，两臂方差不同，所以不用 Student t。
    第 6 步不做 bootstrap：每臂 11 万人以上，均值的中心极限定理成立，t 区间与 bootstrap 区间几乎相同；t 区间是否可靠由第 10 步还原检验实测（CI 覆盖 GMV 真值的比例是否约 95%）。
    逐档 10 个检验 + Holm 属于第 8 步。
  - **每个指标报**：diff（pp 或 GMV）、相对提升 diff / r_C、95% CI、z 或 t、p；再报与真值的对比（数据是模拟的，报告中标明）：
    真值（第 5 节：第 1 档转化 0.100187pp、GMV 0.875912；全体 0.329968pp、1.395263），(估计 − 真值) / SE，CI 是否覆盖真值。
  - **解读规则**（第 1 档功效 8.5%，第 5 节）：
    - p ≥ 0.05（预期约 91.5%）：写「第 1 档未检出效应；95% CI 上界 X pp，即排除了大于 X 的效应」，**不写「券无效」**。
    - p < 0.05（约 8.5%）：照实报告显著，同时注明估计值大概率被夸大：要显著，估计至少要 1.96 × SE ≈ 1.96 × 0.155 = 0.30pp
      （SE 取 A/A 实测的第 1 档 0.155pp），至少是真值 0.1pp 的 3 倍。功效低时「显著」本身就是一道筛选（Type M 误差，与赢家诅咒同一回事）。
    - 无论哪种结果，都不换检验、不换段、不加协变量重跑；结果如实写进本节。

## 4. 功效分析

人群和分组已定，N 固定，所以功效分析倒过来做：给定 n 求 MDE，全体和每档各一遍。

```
MDE = (z_{1-α/2} + z_{1-β}) × sqrt( p(1-p) × (1/n_t + 1/n_c) )
等分时反解 n：n = (z_{1-α/2} + z_{1-β})² × 2p(1-p) / δ² ≈ 16 p(1-p) / δ²
```

- [x] **决定（Andy，2026-10-02）：双侧 α = 0.05，功效 80%**（z 值 1.96 + 0.84 = 2.80）。惯例取值，主检验只有一个，不另作调整。

## 5. 注入的效应 τ（模拟的假设，不是发现）

τ_d = 第 d 档的人如果全都拿到券，转化率比不拿券高多少（绝对值，pp）。形状沿用 `model_report.md` §9：
倾向不等于增量，高分段多是不发券也会买的人，τ 接近 0；中间档最高。

- [x] **决定（Andy，2026-10-03）：第 1 档 τ₁ = 0.1pp，低于该档 MDE（0.48pp），主检验的功效约 8.5%**。
  **主检验预期不显著，这是设计，不是实验失败**：效应存在但这次实验分不出来，用来演示「不显著 ≠ 没有效应」。
  全体平均 τ = 0.33pp，远高于全体 MDE（0.080pp），全体检验预期显著。
- [x] **决定（Andy，2026-10-03）：单峰，峰在第 5 档；不设负效应；按档设阶梯值，写进配置**。
  - 单峰：真实的最优档唯一。若第 3–7 档等高，「按增量发」挑哪档全凭噪声，策略对比就成了比运气。
  - 不设负效应（sleeping dogs，Y(0) = 1、Y(1) = 0）。机制是存在的：收券后观望更好的优惠；

## 6. 方差缩减（CUPED）

```
Y_cv = Y − θ × (X − mean(X))，θ = Cov(X, Y) / Var(X)，两臂合起来估一个 θ
Var(Y_cv) = Var(Y) × (1 − ρ²)；SE、MDE × sqrt(1 − ρ²)；等价样本量 × 1 / (1 − ρ²)
```

X 在实验前测得、不受券影响，随机分组下两臂 X 的期望相等，减掉的部分两臂抵消，估计仍无偏，只有方差变小。

- [x] **决定（Andy，2026-10-03）：预注册选择规则，不直接指定协变量——在验证集上算每个候选与 label 的 ρ²，转化率用 ρ² 最大的；GMV 用 `total_spend_per_day`**。
  - 候选（都在截止日之前测得）：`purchase_days_per_day`、`n_purchases_per_day`、`total_spend_per_day`、模型分数 p（CUPAC：用模型预测值作协变量）。
  - 在验证集上选，测试集的结果不参与决策，和第 4 节的基线同理。
  - 断档：协变量「脏」不会造成偏差（只要是实验前测得的，上面的无偏论证照样成立），代价只是 ρ 变小。
    所以选 `*_per_day` 是为了效率，不是为了正确性。验证集的特征窗口 10/18–31 没有断档，原始计数与 `*_per_day` 只差 ÷14，
    ρ 完全相同、分不出高下；测试集上用 `*_per_day` 靠的是事前推理（断档让原始计数低估了断档期活跃的用户）。
  - 档内的 ρ 要和全体的 ρ 分开实测：分档按 p 切，同档的人实验前的购买频率也相近，档内 ρ 预计比全体小。
  - 第 4 节的 MDE 表没用 CUPED，是保守的一边。
