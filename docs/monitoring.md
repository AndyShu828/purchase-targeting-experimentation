## 3. 表现：lift@10%

- [x] **决定（Andy，2026-10-14，算出任何一天的实际 lift 之前）：指标 = lift@10%；报警线 = valid 的 lift@10% 下跌 20%，即 4.2920 × 0.8 = 3.4336，低于 3.43 报警**。
  - 理由：P3 的 test 已经比 valid 掉了 12.8%（4.2920 → 3.7407，`docs/model_report.md` 第 4 节），20% 比这个宽，不会被已知的衰减触发。
  - 用 lift@10% 不用 AP：AP 随正例率变（valid 5.00% → test 4.44%），不能跨日期比；lift 除掉了正例率。P4 发券只发前一档，掉得最多的也是这一档。
  - 不选「打不过 RFM 就报警」：业务含义最清楚（输给简单规则就退回规则），但每个 cutoff 要再给 RFM 打一次分。记为以后的扩展。
- [x] **决定（Andy，2026-10-16）：选 lift@10% 的理由以「衰减集中在头部」为准**（P3 test：ROC-AUC 0.7657 → 0.7614 几乎不动，lift@10% −12.8%）。上面「P4 发券只发前一档」是 P4 预注册时的设定，P4 策略分析的结论是按估计增量发（模拟效应下为第 5 档，`docs/experiment_report.md` 第 1 节第 3–4 条），不再作为理由。指标和报警线不变。
- **能算的日期**：数据到 11-30 结束，标签窗口要走完 14 天，所以只有 cutoff 10-15 … 11-17 共 34 天；PSI 有 48 天（到 12-01）。
- **读曲线时要注明的三处**（推断，算出来之前未验证）：
  - 10-15 是训练集的 cutoff（样本内）；10 月其余几天的标签期和训练期（10-15 … 10-28）重叠，可能偏乐观。
  - 11-01 是 valid（调参、early stopping、Platt 都用它），4.2920 本身偏乐观 —— 报警线以它为基准，相当于更严。
  - 11-14 18:09 → 11-16 08:32 的购买断档落在 cutoff 11-01 … 11-16 的标签窗口里，标签少记了购买；对 lift 的方向不确定（分子分母都受影响）。
